## Proyectos propios y herramientas seleccionadas

Los proyectos personales y las herramientas desarrolladas durante etapas laborales se incluyen como contexto profesional; no implican un trabajo a tiempo completo para cada proyecto.

### Lazy Lands (2026)

- Web: https://lazy-lands.com/
- Asistente de campañas de rol con memoria supervisada entre sesiones.
- Tecnologías: Next.js, FastAPI, Supabase e integración de modelos LLM.
- Decisión de producto: la IA sugiere recuerdos, pero la dirección de juego decide cuáles pasan a ser canon.

### Hotel Sur (2025)

- Web: https://hotelsur.es/
- Web para una banda musical, con diseño visual, interacción y desarrollo usando Next.js, Tailwind CSS y GSAP.

### Holy Seitan (2025)

- Web: https://holy-seitan.danilopgon.com/
- Aplicación de recetas con contenido en Markdown, Next.js, Supabase, Drizzle ORM y Shadcn/UI.

### Día de Gachas (2025)

- Web: https://www.diadegachas.danilopgon.com/
- Aplicación meteorológica con frontend Angular y backend NestJS. Evolucionó hacia un modelo de snapshots periódicos de previsiones de AEMET para miles de municipios, con despliegue en Railway.

### Pirineos sin bus (2026)

- Web: https://pirineos-pwa.vercel.app/
- Código: https://github.com/danilopgon/pirineos-pwa
- Guía de senderismo **offline-first** para un viaje por Benasque, hecha con React, TypeScript y Vite.
- PWA instalable con Workbox, contenido tipado, perfiles de altitud y enlaces a Organic Maps; conserva el estado localmente y está diseñada para seguir funcionando sin cobertura.

### El Rincón del Trabajador (2026)

- Web: https://elrincondeltrabajador.com/
- Código: https://github.com/danilopgon/el-rincon-del-trabajador
- Web comercial desarrollada con **Astro 6, React 19, Tailwind CSS y GSAP**, combinando HTML estático e islas interactivas.
- Trabajo realizado junto a **Grajo Estudio**. [Crédito externo del estudio](https://es.linkedin.com/posts/grajo-estudio_el-rinc%C3%B3n-del-trabajador-por-grajo-estudio-activity-7469414542893150208-CI8v).

### Lorekeeper (2026, en desarrollo)

- Código: https://github.com/danilopgon/lorekeeper
- Proyecto de memoria y consulta de campañas de rol con **Angular 22, ASP.NET Core/.NET 10 y PostgreSQL**.
- Implementa las primeras piezas de gestión de campañas; la ingesta de fuentes y el sistema de recuperación híbrida/RAG forman parte de la evolución prevista, no de un producto terminado.

### DTFetris (2026, prototipo)

- Código: https://github.com/danilopgon/DTFetris
- Aplicación de escritorio en desarrollo para preparar planchas de impresión DTF, con **Tauri, React, TypeScript y Rust**.
- Incluye estructura de interfaz, dominio y validación de entradas. El algoritmo de distribución automática de diseños todavía está pendiente de implementación.

### Developer tooling durante la etapa en Servinet

- **ApeReview:** servidor MCP con Python/FastAPI, SQLite y FTS5 para recuperar conocimiento técnico de revisiones y convenciones.
- **figma-dom-audit:** auditoría entre diseños Figma y el DOM, con comprobaciones medibles de dimensiones, tokens y estilos.
- **sonar-diff-review:** revisión de hallazgos de Sonar acotada al diff con contexto de los cambios.
- **docker-push-acr:** automatización de construcción y publicación de imágenes en Azure Container Registry, con confirmación humana previa.
